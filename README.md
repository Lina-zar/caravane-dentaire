# Caravane Dentaire

Application hors ligne pour les caravanes dentaires : enfants (REF automatique, état de santé), actes, médicaments et produits remis, stock de pharmacie, équipe, planning et bilan, avec export Excel.

Les données restent sur le téléphone. Ce dépôt ne contient que le code de l'application.

- **Android** : télécharger `Caravane-Dentaire.apk` dans la page *Releases* (« latest »), l'ouvrir et autoriser l'installation.
- **iPhone** : ouvrir le lien GitHub Pages dans Safari → Partager → « Sur l'écran d'accueil ».
